# Visite Barueri

Projeto de TCC com foco em apresentar pontos turísticos, cultura e opções de lazer da cidade de Barueri.

## Tecnologias

- HTML
- CSS
- JavaScript
- Supabase

## Funcionalidades

- Informações sobre pontos turísticos
- Mapa de Barueri
- Cadastro e login
- Recuperação de senha
- Perfil de usuário com foto, nome e bio
- Alteração básica de senha

## Estrutura

- `index.html` — página inicial
- `locais.html` — lista de atrações
- `perfil.html` — perfil do usuário
- `css/` — estilos
- `js/` — autenticação e perfil
- `images/` — imagens locais do projeto

## Objetivo

Facilitar o acesso a informações básicas sobre atrações de Barueri em uma interface simples e responsiva.

## Observação

Este repositório é usado como ambiente de testes antes das alterações serem levadas ao repositório principal do projeto.
